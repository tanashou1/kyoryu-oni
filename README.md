# きょうりゅうと あそぼ

2歳から遊べる、恐竜のミニゲーム3つ。最初のページで好きなゲームの絵を選べます。

🎮 [ゲームであそぶ（GitHub Pages）](https://tanashou1.github.io/kyoryu-oni/)

- **おいかけっこ**：逃げるお友だちを「ぽん！」の連打で追いかけます。止めると離れ、続けて押すと追いついてタッチ。1秒に1〜2回のタップで追いつける速さです。離れる距離に上限があり、何度でも追いかけられます。
- **たまご ぱかっ**：「こんこん！」を4回押すと、卵から赤ちゃん恐竜が生まれます。
- **もぐもぐ ごはん**：「はっぱ どうぞ！」を5回押すと、恐竜がおなかいっぱいになります。

どれも「あそぶ！」からスタート。時間制限・ゲームオーバーなし。音は初期状態でオフ。ゲーム画面の「あそびを えらぶ」で選択ページに戻れます。スマートフォン、タブレット、パソコンに対応します。

依存ライブラリや外部通信のないHTML/CSS/JavaScriptです。`index.html`をブラウザで開くと遊べます。GitHub Pagesはmainブランチのルートから公開します。
