# きょうりゅうと あそぼ

2歳から遊べる、恐竜のミニゲーム3つ。最初のページで好きなゲームの絵を選べます。

🎮 [ゲームであそぶ（GitHub Pages）](https://tanashou1.github.io/kyoryu-oni/)

- **おいかけっこ**：逃げるお友だちを「ぽん！」の連打で追いかけます。止めると離れ、続けて押すと追いついてタッチ。1秒に1〜2回のタップで追いつける速さです。離れる距離に上限があり、何度でも追いかけられます。
- **たまご ぱかっ**：卵を指やマウスでなでると、赤ちゃん恐竜が生まれます。手のアニメーションが操作を案内します。キーボードでは卵にフォーカスして左右キーでも操作できます。
- **もぐもぐ ごはん**：「ごはん どうぞ！」を5回押すと、恐竜がおなかいっぱいになります。種類に合わせて葉っぱ・魚・肉が登場します。

どれも「あそぶ！」からスタート。時間制限・ゲームオーバーなし。音は初期状態でオフ。ゲーム画面の「あそびを えらぶ」で選択ページに戻れます。スマートフォン、タブレット、パソコンに対応します。

依存ライブラリや外部通信のないHTML/CSS/JavaScriptです。`index.html`をブラウザで開くと遊べます。GitHub Pagesはmainブランチのルートから公開します。

## 登場する恐竜たち

ティラノサウルス、アロサウルス、カルノタウルス、スピノサウルス、ステゴサウルス、モササウルス、ギガントサウルス、プルスサウルス、トリケラトプス、プテラノドン、アルゼンチノサウルスの11種類。毎回ランダムに選び、体型や角・翼・背びれなどを描き分けたオリジナルのベクターイラストで表示します。モササウルス・プテラノドン・プルスサウルスは、恐竜と同じ仲間ではない古代の爬虫類も含めたラインナップです。卵の孵化や一緒に遊ぶ表現は幼児向けのファンタジーです。

追いかけっこのクリア後は連打ボタンを無効にし、画面上部の別の位置に「もう いっかい！」を表示します。
